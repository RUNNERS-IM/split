# Split

[English](README.md) · **한국어**

키보드 단축키로 macOS 창을 옮기고 크기를 맞추는 앱입니다. 마우스가 필요 없습니다.

Split 은 RUNNERS 가 만드는 무료 창 정렬 앱입니다. Apple 실리콘 · 인텔 맥 유니버설 빌드, 공증된 배포판, 창 자동 배치 · 배치 저장, 20개 언어를 지원합니다.

## 설치

1. [Releases](https://github.com/RUNNERS-IM/split/releases) 에서 `Split-<버전>.dmg` 를 받아 열고 Split 을 응용 프로그램 폴더로 끌어 놓습니다. 서명·공증된 앱이라 경고 없이 열립니다.
2. 처음 켜면 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용** 이 자동으로 열립니다. Split 옆 스위치를 켜면 됩니다. 이 권한이 없으면 다른 앱의 창을 움직일 수 없고, 켜는 순간 안내 창이 스스로 닫힙니다.
3. 예전 창 정렬 앱이 아직 켜져 있으면 Split 이 끌지 물어봅니다. 두 앱이 같은 단축키에 함께 반응하지 않게 하려는 것입니다.

애플 실리콘·인텔 맥 모두에서 네이티브로 돌고, macOS 13 이상이 필요합니다. 업데이트는 앱 안에서 설치됩니다.

Homebrew 로 설치하려면:

```sh
brew tap runners-im/tap
brew trust runners-im/tap   # 최신 Homebrew 는 공식 목록 밖 저장소를 한 번 믿어 달라고 합니다
brew install --cask split
```

Split 은 한국어, 영어, 일본어, 중국어(간체), 독일어, 프랑스어, 스페인어, 이탈리아어, 포르투갈어, 네덜란드어, 폴란드어, 러시아어, 아랍어, 힌디어, 인도네시아어, 태국어, 베트남어, 핀란드어, 튀르키예어, 중국어(번체)로 나옵니다. 맥에 설정한 언어를 따라갑니다.

## 기본 단축키

| 기호 | 키 |
|:---:|:---|
| ⌘ | 커맨드 |
| ⌃ | 컨트롤 |
| ⌥ | 옵션 |
| ⇧ | 시프트 |

모든 단축키는 설정 → 단축키에서 바꾸거나 지울 수 있습니다.

### 기본 동작

- 가운데 — ⌥⌘C (크기는 그대로)
- 전체 화면 — ⌥⌘F
- 왼쪽 반 — ⌥⌘←
- 오른쪽 반 — ⌥⌘→
- 위쪽 반 — ⌥⌘↑
- 아래쪽 반 — ⌥⌘↓
- 왼쪽 위 — ⌃⌘←
- 왼쪽 아래 — ⌃⇧⌘←
- 오른쪽 위 — ⌃⌘→
- 오른쪽 아래 — ⌃⇧⌘→

반·모서리 단축키를 반복해서 누르면 그 영역에서 1/2 → 3/4 → 1/4 로 번갈아 바뀝니다.

### 자동 배치

- 창 모두 자동 배치 — ⌥⌘A

맨 앞 창이 있는 모니터에서 보이는 창을 최근에 쓴 순서로 9개까지 한 번에 놓습니다.

| 창 개수 | 배치 |
|:---:|:---|
| 1 | 전체 화면 |
| 2 | 왼쪽 반 · 오른쪽 반 |
| 3 | 왼쪽 반 + 오른쪽 위아래 |
| 4 | 2 × 2 네 칸 |
| 5 | 네 칸 + 맨 앞 창을 가운데 60% 크기로 띄움 |
| 6 | 3 × 2 여섯 칸 |
| 7–9 | 여섯 칸 + 나머지를 가운데 60% 크기로 30포인트씩 어긋나게 겹침 |

최소화한 창, 전체 화면 창, 가린 앱의 창은 건드리지 않습니다. 되돌리기(⌥⌘Z) 한 번이면 옮긴 창이 전부 원래 자리로 돌아갑니다. 메뉴에서 이 항목에 마우스를 올리면 각 창이 갈 자리가 미리 보입니다.

### 3등분

- 다음 1/3 — ⌃⌥→
- 이전 1/3 — ⌃⌥←

### 크기 조절

- 키우기 — ⌃⌥⇧→
- 줄이기 — ⌃⌥⇧←

크기를 바꿀 때 창이 이미 닿아 있는 화면 가장자리는 계속 붙어 있습니다.

### 여러 모니터

- 다음 모니터 — ⌃⌥⌘→
- 이전 모니터 — ⌃⌥⌘←

### 되돌리기

- 마지막 동작 취소 — ⌥⌘Z
- 다시 실행 — ⌥⇧⌘Z

⌥⌘ 를 1초 누르고 있으면 단축키 목록이 화면에 뜹니다. 설정에서 끌 수 있습니다.

### 단축키 잠시 끄기

다른 앱이 같은 키를 써야 할 때는 Split 메뉴에서 **단축키 잠시 끄기** 를 고릅니다.

- **1시간 동안** — Split 단축키가 1시간 동안 모두 꺼집니다.
- **(앱) 앱을 쓰는 동안** — 그 앱이 맨 앞에 있을 때만 Split 단축키가 꺼지고, 다른 앱으로 옮기면 바로 다시 켜집니다. 그 앱을 맨 앞에 둔 채 같은 항목을 다시 고르면 단축키가 다시 켜집니다.

## 실행 인자

Releases 나 Homebrew 로 받은 판에서 확인했습니다. 맥 앱스토어판에서는 아직 해 보지 않았습니다. Split 이 이미 켜져 있어야 하고, 인자는 켜져 있는 Split 에 전달됩니다.

```sh
open -g -a Split --args --perform MoveToLeftHalf   # 창 동작 하나 실행 (스크립트 · 실행기용)
open -g -a Split --args --menu                     # 마우스 자리에 Split 메뉴 띄우기
open -g -a Split --args --guide                    # 손쉬운 사용 안내 다시 보기
```

`--perform` 에 쓰는 동작 이름은 MoveToCenter, MoveToFullscreen, MoveToLeftHalf, MoveToRightHalf, MoveToTopHalf, MoveToBottomHalf, MoveToUpperLeft, MoveToUpperRight, MoveToLowerLeft, MoveToLowerRight, MoveToNextThird, MoveToPreviousThird, MoveToNextDisplay, MoveToPreviousDisplay, MakeLarger, MakeSmaller, UndoLastMove, RedoLastMove, ArrangeWindows 입니다. 인자 없이 Split 을 한 번 더 열면 설정 창이 뜹니다.

## 자주 생기는 문제

### 손쉬운 사용 권한을 요구합니다

Split 은 macOS 의 손쉬운 사용(Accessibility) 프로토콜로 다른 앱의 창을 움직입니다. **시스템 설정 → 개인 정보 보호 및 보안 → 손쉬운 사용** 에서 허용하기 전에는 동작하지 않습니다.

### 창이 생각한 크기로 안 바뀝니다

앱은 자기 창의 최소·최대 크기를 정해 둘 수 있습니다. Split 은 그 제한을 항상 지키므로, 최소 폭이 1600px 인 창은 1440px 인 화면 절반에 들어갈 수 없습니다. 앱이 허용하는 한도 안에서 가장 가깝게 맞춥니다.

### 터미널 창이 이상하게 움직입니다

터미널과 비슷한 앱(iTerm2 등)은 글자 행·열이 온전히 보이는 크기만 허용합니다. Split 은 먼저 정확한 크기를 시도하고, 안 되면 들어갈 때까지 조금씩 줄입니다. 그래서 살짝 덜컹거려 보일 수 있고, 결과는 목표 영역 가운데에 놓입니다.

### Split 아이콘이 노치에 가려졌습니다

노치가 있는 맥북에서 메뉴 막대가 꽉 차면 Split 아이콘이 노치 밑으로 밀려 안 보일 수 있습니다. Split 을 한 번 더 열면(응용 프로그램 폴더나 Spotlight) 설정 창이 뜨고, `open -g -a Split --args --menu` 를 실행하면 마우스 자리에 Split 메뉴가 뜹니다. 설정에서 메뉴 막대 아이콘을 꺼 둔 때도 같습니다.

### 어떤 앱은 아예 안 됩니다

화면을 비표준 방식으로 그리는 앱은 손쉬운 사용 프로토콜로 창을 드러내지 않습니다. 그런 창은 Split 이 움직일 수 없습니다.

## 소스에서 빌드하기

Xcode 26 이상이 필요합니다. 외부 부품은 Swift Package Manager 로 Xcode 가 받아 옵니다.

```sh
open Split.xcodeproj
```

⌘R 로 실행, ⌘U 로 테스트합니다. 배포는 `scripts/release.sh <버전>` 으로 합니다. 테스트·Developer ID 서명·공증·Sparkle 업데이트 목록까지 만들고, `--publish` 를 붙이면 GitHub Releases 에 올립니다.
